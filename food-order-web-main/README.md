# Foodie Delight

Foodie Delight is a static food ordering website built with HTML, CSS, and JavaScript. It includes a home page, menu page, about page, contact page, shopping cart modal, and order bill preview.

## Pages

- `index.html` - Main home page with featured items and food categories.
- `menu.html` - Full menu page with category filters.
- `about.html` - Restaurant story, mission, and quality details.
- `contact.html` - Contact form and restaurant contact information.


## Features

- Responsive website layout.
- Food category cards and featured menu items.
- Add-to-cart functionality with item quantity controls.
- Cart data saved in browser local storage.
- Checkout flow with bill preview.
- Bill download as text file.
- Print-friendly bill view for PDF saving.
- Contact form data saved in browser local storage.

## How to Run

Open `index.html` in a web browser.

For the project overview page, open `project-index.html`.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Browser local storage

## Notes

This project does not require a backend server. Cart, order, and contact form data are stored locally in the user's browser.
